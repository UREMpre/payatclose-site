# payatclose.615.media

The Pay at close page for 615 Media: one static page (`index.html`, no build step), the one-page PDF it is based on,
and the images it uses.

**Hosting:** GitHub Pages from this repo (`main`, root), custom domain in `CNAME`. DNS: `payatclose` CNAME
`urempre.github.io`.

**To change the page:** edit `index.html`, commit and push to `main`. Pages redeploys in about a minute. If the fee
tiers or wording change, update the PDF too so the two never disagree.

`og.png` is the 1200 × 630 picture shown when the link is texted or shared.
